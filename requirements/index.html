= Сервис работы с задачами Настоящий документ содержит техническое описание HTTP-сервиса работы с задачами. Сервис позволяет: . Создавать задачи (POST). . Получать список созданных задач (GET). . Получать конкретную задачу из списка (GET). . Изменять параметры задачи (PUT). . Удалять задачу (DELETE). = Структура данных сервиса работы с задачами Структур данных, используемая сервисом работы с задачами, приведена в таблице. .Структура данных |=== |*Атрибут* |*Ключ* |*Тип* |*Не пустой* |*Описание* |Заголовок |title |Однострочный текст |true |Краткое описание задачи. Длинна не более 255 символов |Описание |description |Многострочный текст |false |Полное описание задачи, что необходимо сделать |Статус |status |Однострочный текст |true a|Статус исполнения задачи. Одно из значений: * `todo` - к исполнению; * `in progress` - в работе; * `done` - исполнена; * `declined` - отменена. По умолначнию `todo` |=== Структур данных, используемая сервисом работы с задачами, приведена на диаграмме.
