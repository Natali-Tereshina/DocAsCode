== 8. Логика обработки данных

1. МП вызывает метод: GET /v7/restaurants?hash=<hash>.

2. APIGateway перенаправляет запрос в RestaurantComposition.

3. RestaurantComposition вызывает RestaurantService.getRestaurantsList().

4. RestaurantService сравнивает переданный hash с актуальным:

5. если hash совпадает → возвращается только hash;

6. если hash отличается → возвращается новый hash + полный список ресторанов.

7. RestaurantComposition отправляет ответ в APIGateway.

8. APIGateway возвращает ответ МП.
